# AuthFlow

A modern, responsive authentication interface built from scratch with React.

AuthFlow is a frontend authentication project focused on creating a clean, secure-looking and user-friendly sign-in experience without relying on pre-built UI templates.

## ✨ Features

- Modern sign-in interface
- Create account / sign-up flow
- Forgot password flow
- Email validation
- Password validation
- Password strength indicator
- Confirm password validation
- Show / hide password
- Loading states
- Success states
- Responsive design
- Smooth UI animations
- Accessible form labels and controls
- Client-side routing
- Reusable React components

## 🛠️ Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- ESLint
