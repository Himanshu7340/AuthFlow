# AuthFlow

> **Authentication UI Demo:** This is a frontend portfolio/demo project. Do not enter real passwords or personal information. The app does not create accounts, send emails, authenticate users, or transmit credentials to a server.

A modern, responsive authentication interface built from scratch with React.

AuthFlow is a frontend authentication project focused on creating a clean, user-friendly sign-in interface for demonstration and portfolio purposes without relying on pre-built UI templates.

## ✨ Features

- Modern sign-in interface
- Create account / sign-up flow
- Forgot password flow
- Email validation
- Password validation
- Password strength indicator
- Confirm password validation
- Show / hide password
- Loading states
- Success states
- Responsive design
- Smooth UI animations
- Accessible form labels and controls
- Clear demo-only messaging and non-production auth flows
- Client-side routing
- Reusable React components

## 🛠️ Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- ESLint
